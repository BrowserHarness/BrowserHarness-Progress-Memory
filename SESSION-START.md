# Session Start

Before doing work:
1. Read `machine/current-state.json`.
2. Read `machine/current-task.json`.
3. Read `machine/blockers.json`.
4. Read `machine/repositories.json`.
5. Read `machine/workstreams.json`.
6. Use `ROUTER.md` to find the canonical owner.
7. Read that repo's `AGENTS.md`.
8. Verify external/current state before mutation.
9. Reuse an existing workflow/Skill when appropriate.
10. Execute, verify, capture evidence.
11. Update Progress-Memory only after verified state changes.

If state is ambiguous, do not invent completion.
